01 • Basics

What is a Stack?

A Stack is a linear data structure in which insertion and deletion are performed at one end, called the top.

The element inserted most recently is the first element removed. This behavior is called LIFO — Last In, First Out.

Real-life example: Think about a pile of plates. You normally place a new plate on top and remove the top plate first.
02 • Core Idea

LIFO — Last In, First Out

Suppose we insert 10 → 20 → 30. The last inserted element, 30, is at the top.

10
20
30 ← TOP

If we perform one deletion, 30 is removed first. Then 20 becomes the top.

03 • Operations

Basic Stack Operations

Push

Adds an element to the top of the stack.

push(40) places 40 above the current top.

Pop

Removes and returns the element from the top.

pop() removes the current top element.

Peek / Top

Returns the top element without removing it.

peek() or top() lets us see the top.

isEmpty

Checks whether the stack contains any elements.

Returns true when there is no element in the stack.
Important: Stack operations are performed from the top. We do not normally insert or delete from the middle.
04 • Implementation

How Can We Implement a Stack?

A Stack can be implemented using an array or a linked list. The important idea is to keep track of the current top.

Using an Array

Store elements in an array and maintain an integer called top. Initially, top can be set to -1 for an empty stack.

  • Push: increase top and place the element.
  • Pop: read the top element and decrease top.
  • Peek: read the element at top.

Using a Linked List

Use the head node as the top of the stack. New nodes are added at the beginning and removed from the beginning.

  • No fixed array size is required.
  • Push and pop can work at the head.
05 • Applications

Where Are Stacks Used?

  • Function calls and recursion: function calls are managed using a call stack.
  • Balanced parentheses: useful for checking whether brackets are correctly matched.
  • Expression evaluation: stacks are used in infix, prefix and postfix expression processing.
  • Undo operations: previous actions can be stored so the latest action can be reversed first.
  • Backtracking: useful when we need to return to a previous state.
  • Depth First Search: DFS can be implemented using a stack.
  • Next Greater Element and Stock Span: stack-based techniques are common in array problems.

09 • Code

Simple C++ Stack

#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> st;

    st.push(10);
    st.push(20);
    st.push(30);

    cout << st.top() << endl; // 30

    st.pop();

    cout << st.top() << endl; // 20

    return 0;
}

Quick Revision

  • Stack follows LIFO.
  • Top is the end where insertion and deletion happen.
  • Push adds an element.
  • Pop removes the top element.
  • Peek / Top reads the top element.
  • Stacks can be implemented using arrays or linked lists.
  • Stacks are useful in recursion, expressions, parentheses, DFS, undo and backtracking.
