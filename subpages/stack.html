01 — FOUNDATION

What is a Stack?

A Stack is a linear data structure where insertion and deletion happen at one end called the top.

↥

LIFO

Stack follows Last In, First Out. The last element added is the first element removed.

▣

One Open End

Push, pop and peek are performed at the top of the Stack.

⚡

Simple Operations

The core operations are push, pop, peek and checking whether the Stack is empty.

02 — CORE IDEA

LIFO — Last In, First Out

Like a pile of plates: add to the top and remove from the top.

20 was inserted last, so it is removed first. This is LIFO.
03 — OPERATIONS

Important Operations

push

Add an element to the top.

pop

Remove the top element.

peek / top

Read the top element without removing it.

isEmpty

Check whether the Stack is empty.

04 — IMPLEMENTATION

How to Implement a Stack?

A Stack can be implemented using an array or a linked list.
