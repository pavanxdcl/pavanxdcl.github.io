01 — FOUNDATION

What is a Linked List?

A Linked List is a linear data structure made of nodes. Each node stores data and a link to another node.

●

Node

A node contains the data and the link needed to connect it to another node.

→

Connection

Nodes are connected using links, forming a sequence.

↔

Flexible Size

Nodes can be added or removed without requiring a continuous block of memory.

02 — STRUCTURE

How a Linked List Looks

Each node stores a value and a link to the next node. The first node is reached through the head.

03 — NODE

Understanding a Node

Data

The value stored inside the node.

Next

The link that points to the next node.

Head

A pointer or reference used to access the first node.

NULL

The final node points to NULL, indicating the end of the list.

04 — TYPES

Types of Linked Lists

Singly Linked List

Each node points only to the next node.

Doubly Linked List

Each node contains links to both the previous and next nodes.

Circular Linked List

The last node links back to the first node instead of pointing to NULL.

05 — OPERATIONS

Important Operations

Most Linked List problems are built around a few fundamental operations.

Traversal

Visit nodes one by one from the head.

Insertion

Add a new node at a required position.

Deletion

Remove a node by changing the required links.

Search

Traverse the list to find a required value.

06 — INSERTION

Insertion Step by Step

To insert a node, connect the new node to the correct part of the list and update the surrounding link.

07 — DELETION

Deletion Step by Step

Deletion usually means changing a link so that the unwanted node is skipped.

09 — APPLICATIONS

Where Linked Lists Are Used

Dynamic Data

Useful when elements are frequently inserted and removed.

Stacks & Queues

Linked Lists can be used to implement these data structures.

Memory Management

Linked structures are useful in systems where flexible allocation is needed.

Graph Representation

Linked structures can help represent adjacency relationships.
