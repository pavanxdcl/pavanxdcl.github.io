01 — FOUNDATION

What is a Dynamic Array?

A dynamic array behaves like an array but can grow when more elements are needed.

▣

Resizable

When capacity is reached, a larger backing array can be allocated and elements copied over.

⚡

Fast Access

Index-based access is O(1) because elements live in contiguous array storage.

＋

Amortized Append

Adding at the end is usually amortized O(1), with occasional O(n) resizing.

04 — OPERATIONS

Important Operations

add / append

Add at the end. Usually amortized O(1).

get / index

Read by index in O(1).

set / update

Replace a value by index in O(1).

remove

Removing can require shifting, so generally O(n).
